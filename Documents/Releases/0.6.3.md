Inspector 0.6.3 fixes a crash at launch on some devices.

- On some devices Inspector closed the moment it opened, while it was drawing the apps' icons (reported on iOS 18 with RootHide). iOS draws those icons with the graphics processor, and Inspector did not ask for access to it. It now asks for the same graphics access as the other OwnGoal apps.
- Every package is now checked for that access before it is published, so a build without it is not released.

Choose `iphoneos-arm64e` for roothide or `iphoneos-arm64` for rootless (`/var/jb`) firmware. SHA-256 checksums are included in `SHA256SUMS`.
