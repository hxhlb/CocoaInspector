Inspector 0.6.2 changes nothing you can see. It is the first release checked to open on the oldest system it supports before it is published.

- Every package is now examined before release for anything newer than iOS 13 that the app, the service or the command-line tool needs at launch. An app built with newer tools can ask the system for something an older iOS does not have, and then it closes the moment you open it, with no message. A build that does this is no longer published.

Choose `iphoneos-arm64e` for roothide or `iphoneos-arm64` for rootless (`/var/jb`) firmware. SHA-256 checksums are included in `SHA256SUMS`.
